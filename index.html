Draw

Drag with a mouse or finger. Every stroke is copied around the centre of the cloth.

Tune

Change the symmetry from 2 to 16, switch thread colors, and thicken or thin the line.

Keep

About this project

Loom is a single-page generative art studio built for the ROXTEN STUDIOS Website Building Hackathon. It is written in plain HTML, CSS and JavaScript with the Canvas API, with no frameworks or external images. Fonts: Syne and Instrument Sans from Google Fonts.
